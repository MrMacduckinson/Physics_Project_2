# Memebooru
Это прототип локально-ориентированной booru-системы для мемов. Первая версия
сделана на SDL 1.2 и собирается под macOS (10.4+, 10.7+, 11.0+), с целью
дальнейшего расширения на другие платформы.

## Что есть в прототипе
- Локальное хранилище в виде файлов и текстового индекса.
- Экран списка (лента), экран просмотра мема и экран добавления.
- Теги/поля: статус источника, детали источника, свободные теги, текст мема,
  тип файла, ситуативность.
- Поиск по имени файла, тегам и тексту.

## Где хранятся данные
По умолчанию все данные сохраняются в `~/memebooru_data/`:
- `memes.txt` — текстовый индекс (поля через `|`, экранирование `\\` и `\n`).
- Файлы мемов — копии исходных файлов (пока только BMP).

## Требования
- Установленный Retro68 (только если собираете PPC/M68K).
- macOS SDK 10.4u, 10.15 и 11+ (по необходимости для выбранных таргетов).
- Сорцы SDL 1.2 / SDL2 / sdl12-compat находятся в `library_sources/`.

## Сборка
По умолчанию включены macOS 11.0+, 10.7+ и 10.4. Classic-таргеты (M68K/PPC)
отключены по умолчанию.

```shell
cmake -S . -B build
cmake --build build
```

Можно отключать таргеты через CMake-флаги, например:

```shell
cmake -S . -B build -DBUILD_FOR_10_4=OFF -DBUILD_FOR_10_7=OFF -DBUILD_FOR_11_0=ON
cmake --build build
```
